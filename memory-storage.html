記憶體與儲存裝置

Memory & Storage

認識程式執行時暫存資料的 RAM，以及長期保存程式和檔案的 SSD、HDD，並追蹤它們如何協同工作。

學完這一課，你可以

  • 解釋 RAM 和 Storage 在電腦中的不同用途。
  • 分辨 SSD 與 HDD 兩種常見儲存裝置。
  • 說明程式為何從儲存裝置載入 RAM，再由 CPU 執行。

01 / 暫存與保存

電腦為什麼需要兩種存放空間？

使用程式時，電腦需要快速取得目前正在處理的指令和資料；關機後，程式和個人檔案仍應該留在電腦裡。這是兩種不同需求，通常由不同硬體負責。

記憶體（Memory）提供程式執行期間暫時使用的空間。儲存裝置（Storage）則負責長期保存程式和檔案。記憶體讓目前工作的內容容易取用；儲存裝置讓資料在關機後仍能保留。

02 / RAM

程式執行時，資料放在哪裡？

程式開始執行時，CPU 需要反覆讀取指令和資料。為了讓這些內容能快速取用，電腦會把目前工作需要的內容放在隨機存取記憶體（RAM，Random Access Memory）中。RAM 是程式執行時常用的暫存空間。

RAM 的內容通常需要電力維持。電腦關機或斷電後，RAM 裡的內容通常會消失，因此 RAM 也稱為揮發性記憶體（volatile memory）。正在編輯但尚未保存的文件，如果電腦突然關機，可能會遺失最近的變更。

RAM 讓 CPU 能快速存取目前要用的資料；它不是用來永久保存文件的地方。

03 / SSD 與 HDD

檔案如何在關機後保留下來？

程式、照片和文件需要保存到儲存裝置（Storage），讓它們在關機後仍能留存。桌上型電腦和筆電常見的儲存裝置有 SSD 和 HDD。

SOLID-STATE DRIVE

固態硬碟（SSD）

使用快閃記憶體保存資料，沒有用來讀寫資料的旋轉碟片。常用於系統、程式和個人檔案的長期保存。

HARD DISK DRIVE

硬碟（HDD）

使用旋轉的磁性碟片保存資料。也是長期儲存裝置，常見於電腦和外接硬碟。

兩者都能在關機後保存資料，但記錄資料的硬體方式不同。這裡重要的區別是：SSD 和 HDD 屬於 Storage，RAM 則是執行期間使用的記憶體。

04 / 為什麼需要載入 RAM

為什麼程式不一直待在 SSD 裡執行？

SSD 和 HDD 適合保存大量資料，但 CPU 執行程式時，會頻繁讀取指令和資料。若每次處理都要直接向儲存裝置取得所需內容，通常會比使用 RAM 慢，程式回應也會變慢。

因此，作業系統會在啟動程式時，把執行需要的程式內容和資料載入 RAM。CPU 再從 RAM 取得指令和資料並執行。RAM 的空間有限；程式結束後，暫存空間可讓其他工作使用，而原本的程式檔案仍保存在 SSD 或 HDD。

兩種空間，兩種工作

可以把這個差異理解為「目前工作使用的空間」和「關機後仍保存的空間」。對應到電腦裡，前者通常是 RAM，後者是 SSD 或 HDD；實際裝置還有其他細節，本課先看這個基本流程。

07 / 與資安的關係

記憶體和儲存裝置也涉及資料保護

程式執行時，RAM 可能暫存密碼、文件內容或其他敏感資料。程式若錯誤地讀取不屬於自己的記憶體，可能造成記憶體安全（memory safety）問題；本課只建立這個概念，之後再學其成因與防護。

SSD 或 HDD 會保存使用者檔案。刪除檔案不一定代表資料立即從裝置上不可復原，因此敏感資料如何保存、刪除與避免外洩，都需要謹慎處理。實際安全刪除方式會依裝置和系統而不同。

你已經知道

RAM 暫存執行中的程式與資料；SSD、HDD 等 Storage 長期保存檔案。程式通常由 Storage 載入 RAM，再由 CPU 執行。
