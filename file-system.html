檔案系統

File System

了解檔案如何以名稱放進資料夾，並透過路徑讓使用者和程式找到需要的資料。

學完這一課，你可以

  • 說明檔案、資料夾和檔案系統的用途。
  • 分辨絕對路徑與相對路徑。
  • 根據資料夾結構說出檔案的位置。

01 / 檔案

檔案是被保存的一段資料

檔案（file）是以一個整體保存、供程式讀取或修改的一段資料。文字文件、圖片和程式碼都可以存成檔案。檔案內容由電腦保存；檔案名稱則幫助使用者和程式辨認它。

檔名不必描述所有內容，但應讓人比較容易知道用途。例如資料夾中的 logo.png 可能是網站標誌圖片。副檔名常用來提示檔案格式，但不能只靠副檔名保證內容一定符合該格式。

02 / 資料夾

資料夾讓檔案有組織

資料夾（folder）是用來整理檔案，也可以包含其他資料夾。把網站的樣式檔和圖片分開放，能讓結構更清楚，也方便人和程式找到相關內容。

電腦中的資料夾會形成一層一層的結構。要找某個檔案，除了知道它的名稱，也要知道它位於哪個資料夾裡。

03 / 路徑

路徑描述檔案所在的位置

路徑（path）是從某個起點開始，經過資料夾找到檔案的位址。作業系統和程式使用路徑定位資料；只知道檔名時，如果不同資料夾裡有同名檔案，就無法明確知道要找哪一個。

絕對路徑（absolute path）從根目錄（root directory，檔案系統中最上層的資料夾）開始描述完整位置。相對路徑（relative path）則根據目前所在資料夾描述位置。同一個檔案可以依照不同起點有不同的相對路徑，但它的絕對位置不會因此改變。

04 / 檔案系統

作業系統需要管理檔案的位置

檔案系統（file system）是作業系統用來整理和管理檔案及資料夾的方式。它讓程式能依照名稱和路徑找到資料，也讓使用者能建立、瀏覽和保存檔案。

程式通常會要求作業系統依照路徑開啟某個檔案。作業系統再根據目前的檔案系統結構判斷位置，並處理讀取或寫入。程式不必自行理解儲存裝置上每一段資料如何排列。

07 / 與資安的關係

程式必須限制可存取的檔案位置

程式使用路徑開啟檔案。如果程式直接接受使用者提供的路徑，卻沒有確認目標位置是否符合預期，程式可能意外讀取或修改原本不打算提供的資料。

有一類路徑處理問題稱為路徑穿越（Path Traversal）：程式沒有適當限制使用者指定的位置，導致檔案操作超出原本允許的範圍。本課先建立路徑與存取範圍的關係，不進行漏洞利用；之後會再學安全的檔案存取方式。

你已經知道

檔案保存資料，資料夾整理檔案，路徑描述檔案位置。檔案系統管理這些結構，讓程式能透過路徑定位資料。
