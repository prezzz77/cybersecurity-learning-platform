LEVEL 0 — LESSON 0-2

CPU 在做什麼？

Central Processing Unit

了解處理器如何讀取程式指令、使用資料並產生結果。本課只介紹基本執行流程，不討論處理器內部的進階設計。

學完這一課，你可以

  • 解釋 CPU 在電腦中的工作，以及 CPU 不是整台電腦。
  • 說明指令如何指定一項操作，程式如何由多個指令組成。
  • 描述 CPU 如何使用記憶體中的指令和資料完成運算。

01 / 為什麼需要 CPU

電腦需要一個部件執行操作

在 0-1 我們看到，電腦會接收輸入、處理資料，再提供輸出。要計算數字或比較兩個值，必須有部件依照明確步驟執行這些操作。負責這項工作的主要部件叫中央處理器（CPU，Central Processing Unit），中文也常簡稱處理器。

CPU 不是整台電腦。記憶體負責暫時存放執行中會用到的內容，儲存裝置保存程式與檔案，其他裝置則負責輸入和輸出。CPU 會和這些部件協作。

02 / 指令

指令是什麼？

指令（instruction）是要求電腦執行一項操作的描述，例如「把兩個數字相加」或「比較兩個值是否相同」。指令讓程式能把工作拆成電腦可執行的步驟。

程式（program）由一系列有順序的指令組成。開啟計算程式時，它可能依序讀取輸入、執行加法，再把結果交給螢幕顯示。CPU 讀取這些指令並執行它們。

本課範圍

此處的「讀取、理解、執行」是基本概念說明。處理器內部如何安排與加速這些工作，屬於之後的電腦架構課程。

03 / 執行流程

CPU 如何執行指令？

執行程式時，CPU 會取得目前要執行的指令，以及該指令需要的資料。接著依照指令指定的操作處理資料，並保存或傳出結果。這些動作會隨著程式的步驟持續進行。

例如程式要計算 2 + 3：指令指定「相加」，資料是數字 2 和 3；CPU 執行加法，得到結果 5。這張圖把它簡化成四步：

INSTRUCTION指令執行加法
→
CPU處理器執行操作
→
DATA資料2 和 3
→
RESULT結果5

04 / CPU 與資料

指令說明操作，資料是操作對象

CPU 不會憑空知道要算什麼。指令說明要做的操作，資料則提供這項操作所需的內容。對「2 + 3」而言，加法是指令要執行的操作，2 和 3 是資料，5 是運算結果。

同一份資料可以依照不同指令產生不同結果。例如對 2 和 3 執行加法會得到 5；執行比較則會得到「2 小於 3」的判斷結果。

05 / CPU 與 RAM

CPU 從哪裡取得指令和資料？

執行中的程式和目前使用的資料會放在記憶體（Memory）中；一般電腦主要使用隨機存取記憶體（RAM，Random Access Memory）作為暫存空間。CPU 從 RAM 取得執行所需的指令和資料，再把結果交回去或送往其他部件。

RAM 和 CPU 分工不同：RAM 保存目前工作需要的內容，CPU 執行指令。程式檔案通常先從 SSD 或 HDD 載入 RAM，細節會在 0-3 說明。

06 / 完整例子

計算程式執行時發生什麼？

你在計算程式輸入 2 + 3。輸入的數字成為資料，計算程式提供「相加」等指令。程式和輸入資料在執行時由 RAM 暫存，CPU 取得指令與資料並執行加法，最後產生 5，計算程式再將結果顯示出來。

這裡的 2、3、加法指令和結果 5 是不同內容。CPU 負責執行指令，不負責永久保存程式或顯示畫面。

09 / 與資安的關係

指令的執行範圍需要受到限制

CPU 會執行程式要求的指令。若程式可以任意讀取檔案或操作系統資源，出錯或遭濫用時就可能影響其他資料和程式。

作業系統會管理程式的執行環境與資源存取。這會連到權限（privilege，程式可進行的操作範圍）和系統呼叫（system call，程式向作業系統請求服務的方式）。後續課程會再說明這些機制如何限制程式，不在本課展開攻擊技巧。

你已經知道

CPU 依照程式中的指令處理資料；程式執行時，CPU 會使用 RAM 中的指令和資料。CPU 是電腦的一個部件，不是整台電腦。
