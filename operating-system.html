作業系統

Operating System

從程式使用硬體時會遇到的問題，了解作業系統如何管理處理器、記憶體、檔案、使用者和權限。

學完這一課，你可以

  • 說明程式若直接管理硬體，會遇到哪些協調問題。
  • 描述作業系統提供的管理與抽象功能。
  • 連結 CPU、Process、Memory、File System、User 和 Permission 的角色。

01 / 沒有共同管理

每個程式都直接操作硬體會怎樣？

程式需要使用 CPU 執行指令、使用 RAM 暫存資料、從 Storage 讀取檔案，也需要透過鍵盤、滑鼠接收輸入，並把結果送到螢幕。如果每個程式都要自行處理每一種硬體細節，程式會變得複雜，也難以在不同設備上使用。

多個程式若同時自行操作硬體，還需要避免彼此搶用或覆蓋資料。例如兩個程式都要使用記憶體或讀寫同一個檔案時，必須有人協調操作順序與存取範圍。

02 / 作業系統的角色

作業系統管理程式使用的資源

作業系統（Operating System，OS）是管理電腦硬體資源並提供程式使用的系統軟體。它為程式提供一致的操作方式，例如讀取檔案、接收輸入和使用記憶體，並負責協調程式與硬體之間的工作。

程式透過作業系統提出資源使用要求，不必為每一種硬體自行處理所有底層細節。作業系統也會檢查要求是否符合目前使用者和資源的權限。

03 / 管理哪些資源

把 Level 0 的概念連在一起

  • CPU 與 Process：作業系統管理正在執行的程式，協調它們如何使用 CPU。
  • Memory：作業系統管理執行中的程式和資料使用的記憶體。
  • File System：作業系統管理檔案與資料夾，讓程式能依照路徑定位資料。
  • User 與 Permission：作業系統辨認操作身分，並限制可讀取、修改或執行的資源。

鍵盤、滑鼠和螢幕等輸入輸出設備也由作業系統協調使用。程式可以透過一致的操作方式取得輸入或呈現結果，不必各自管理所有硬體細節。

07 / 與資安的關係

作業系統負責執行資源存取規則

使用者和程式會持續要求讀寫檔案、使用記憶體或操作設備。作業系統管理這些資源，並依照權限檢查操作是否允許。若系統不能區分不同使用者或限制 Process 的存取範圍，程式錯誤就更容易影響其他資料和工作。

理解作業系統如何管理資源，是後續學習權限、隔離與系統安全的基礎。本課只整理 Level 0 已介紹的概念，不深入內部實作。

你已經知道

作業系統管理程式與硬體資源的使用，包含 Process、CPU、記憶體、檔案系統、使用者和權限。它提供程式使用資源的方式，也協調多個程式和使用者之間的操作。
