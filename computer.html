LEVEL 0 — LESSON 0-1

什麼是電腦？

Computer Fundamentals

本課從電腦如何接收與處理資料開始，介紹程式、CPU、記憶體和儲存裝置各自負責的工作。

學完這一課，你可以

  • 用輸入、處理、輸出說明電腦的基本工作流程。
  • 分辨資料、程式與 CPU 的角色。
  • 說明程式從儲存裝置載入記憶體後如何執行。

01 / 電腦的工作

電腦到底是什麼？

想想手機計算小費時發生什麼事：你輸入金額和百分比，手機依照計算規則處理數字，最後顯示結果。這種「收到資料、處理資料、提供結果」的裝置，就是我們先要認識的電腦。

把這個流程畫成圖，就是電腦最基本的工作模型。輸入可以是鍵盤按鍵或觸控；輸出可以是螢幕上的文字、聲音或儲存的檔案。

INPUT輸入金額與百分比
→
PROCESSING處理依規則計算
→
OUTPUT輸出顯示計算結果

這只是第一層簡化模型。實際的電腦還需要存放資料的記憶體（Memory）、執行操作的中央處理器（CPU，Central Processing Unit），以及保存程式和檔案的儲存裝置（Storage）。接下來會逐一介紹這些部分。

02 / 資料

電腦處理的是資料

人會直接看出一張照片裡有什麼，或聽出音樂的旋律。電腦本身並不理解「照片」或「音樂」這些人類概念；它依照程式處理資料，再由適當的程式把資料呈現成圖片、文字或聲音。

電腦裡最基本的資料單位是位元（bit），可以記錄兩種狀態，常用 0 和 1 表示。多個 bit 組合起來可以表示更多資訊。位元組（byte）通常由 8 個 bit 組成，是常用的資料大小單位。

二進位（binary）是使用 0 和 1 表示數值的方式。這一課不需要換算二進位；先記得，文字、圖片和音訊在電腦中都會以資料形式保存和處理。

例子

一張圖片檔案是資料。看圖程式依照資料格式讀取內容，才能把它顯示成畫面。

03 / 程式

程式告訴電腦要做哪些操作

程式（program）是一組指令，用來描述電腦要執行哪些操作，以及操作的順序。像計算小費的程式，會讀取輸入的金額和比例、計算結果，再把結果顯示出來。

電腦執行工作時，需要程式提供步驟，也需要資料作為處理對象：

Data 要處理的資料 + Program 操作指令 → Computer performs operations

只看程式，還不一定能知道它會處理哪些內容；只看資料，也不知道要如何處理。程式和資料一起工作，才會產生計算結果。

04 / 執行指令

CPU 負責執行指令

當程式要求電腦計算或比較資料時，需要有部件執行這些指令。中央處理器（CPU）是負責執行程式指令、處理資料的主要部件。

CPU 中央處理器
↓
執行指令
↓
處理資料

CPU 是電腦的重要部件，但不是整台電腦。電腦還需要記憶體存放執行中的資料，需要儲存裝置保存程式和檔案，也需要輸入與輸出設備和人互動。

05 / 暫存與保存

記憶體和儲存裝置有什麼不同？

程式執行時，需要一個地方暫時放正在使用的指令和資料。這個地方通常是記憶體（Memory）；一般電腦的主要記憶體是隨機存取記憶體（RAM，Random Access Memory）。RAM 供執行中的程式快速讀寫，關機或斷電後，其中的內容通常會消失。因此 RAM 也稱為揮發性記憶體（volatile memory）。

程式和檔案則需要在關機後仍能保存。負責長期保存資料的裝置稱為儲存裝置（Storage），例如固態硬碟（SSD）或硬碟（HDD）。關機後，存放在 SSD 或 HDD 的檔案通常仍然存在。

07 / 與資安的關係

程式能做什麼，為什麼和資安有關？

程式會使用記憶體、讀取檔案、接收輸入，並執行指令。系統需要決定程式可以存取哪些資料、可以進行哪些操作，也要處理不符合預期的輸入。

例如，程式通常不應讀取與工作無關的私人檔案，也不應把使用者輸入直接當成系統命令執行。如何限制程式的存取範圍，以及如何安全處理輸入，都是資訊安全要處理的問題。後續課程會介紹使用者權限、程序（Process，正在執行中的程式）隔離和輸入驗證。
