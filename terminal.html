Terminal 與 Command Line

Terminal & Command Line

認識文字介面如何接收命令、要求作業系統操作檔案，並回傳結果。本課的命令練習只在模擬器中執行。

學完這一課，你可以

  • 分辨 Terminal、Shell 與 Command Line。
  • 說明命令如何透過 Shell 要求作業系統執行操作。
  • 使用目前位置與路徑理解 pwd、ls 和 cd 的結果。

01 / Terminal

用文字與電腦互動的介面

終端機（Terminal）是讓使用者以文字輸入和查看結果的介面。它不是作業系統，也不是命令本身；它提供一個地方，讓使用者透過文字方式與系統互動。

終端機裡常會執行Shell（命令解譯程式）。Shell 是一種接收使用者命令、解析命令並要求作業系統執行操作的程式。使用者輸入的命令和 Shell 提供的文字互動方式，合稱命令列介面（Command Line Interface，CLI）。

USER使用者輸入命令
→
TERMINALTerminal文字輸入與結果顯示介面
→
SHELL / CLIShell解析命令、提出操作要求
→
OS作業系統處理檔案或其他操作

Terminal 提供文字互動視窗；Shell 解讀命令並提出要求；作業系統負責依照規則處理資源。三者有關聯，但不是同一個東西。

02 / Command

命令如何得到結果？

命令（command）是使用者輸入、要求系統完成特定操作的文字。例如 pwd 要求顯示目前所在資料夾，ls 要求列出目前位置的內容，cd 則要求切換目前位置。

  • 輸入 pwd：要求顯示目前位置；結果是資料夾路徑。
  • 輸入 ls：要求列出目前資料夾內容；結果是其中的檔案和資料夾名稱。
  • 輸入 cd project：要求切換至 project 資料夾；成功後目前位置會改變。

Shell 會解析命令文字，再請作業系統完成相應操作。作業系統回傳結果後，Terminal 顯示出來。這些簡單命令和 0-6 學過的路徑、資料夾直接相關。

03 / 目前位置與路徑

相對路徑從目前位置開始

在命令列中，目前位置（current working directory）是命令預設操作的資料夾。pwd 顯示目前位置；ls 列出該位置的檔案和資料夾；cd 改變目前位置。

目前位置會影響相對路徑的意思。例如目前位於 project/，相對路徑 css/style.css 指向 project 裡 css 資料夾的檔案。絕對路徑則從檔案系統根目錄描述完整位置，不依賴目前位置。

和檔案系統的關係

命令列不會改變檔案如何組織。Shell 使用路徑表達操作目標，作業系統依據檔案系統找到對應的資料夾或檔案。

04 / 互動示意

在模擬 Terminal 中執行命令

可輸入 pwd、ls、cd project、cd ..、help 或 clear。模擬器只處理這些預先定義的命令，不會執行系統 Shell 或其他命令。

模擬器 · 僅處理指定命令目前位置：/home/learner

輸入 help 查看可用命令。此為模擬環境，沒有連接本機檔案或命令列。

命令會由模擬 Shell 判讀，再顯示預先定義的結果。

06 / 與資安的關係

命令會以目前使用者的權限執行

Terminal 中輸入的命令可能要求系統讀寫檔案或啟動程式。命令能做什麼，會受到目前使用者權限和作業系統檢查的影響；因此只應執行理解且可信任的命令。

程式若把使用者提供的文字直接當成命令交給系統執行，資料可能被誤當成操作，這類問題稱為命令注入（Command Injection）。本課只介紹這個風險概念，不提供攻擊命令或實際利用方式。

你已經知道

Terminal 是文字互動介面，Shell 解析命令並要求作業系統操作資源。pwd、ls、cd 分別查看位置、列出內容和切換資料夾；目前位置會影響相對路徑。
