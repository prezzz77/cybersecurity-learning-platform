程式與 Process

Program & Process

比較儲存中的程式內容和正在執行中的一次活動，了解作業系統如何讓一份程式開始工作。

學完這一課，你可以

  • 說明 Program 和 Process 分別代表什麼。
  • 描述程式載入 RAM 後，作業系統如何建立 Process。
  • 解釋同一個 Program 為什麼可以同時有多個 Process。

01 / 回顧 Program

Program 是可以執行的內容

程式（Program）是一組描述操作的指令，以及執行時會用到的相關資料。它可以保存在 SSD 或 HDD 上，即使目前沒有執行，程式檔案仍然存在。

例如文字編輯器的程式檔案可以留在儲存裝置中。檔案存在不代表文字編輯器正在運作；它只代表電腦有一份可供載入的程式內容。

02 / 從 Program 到 Process

作業系統建立一次執行活動

當使用者開啟程式，作業系統（Operating System）會把程式執行需要的內容載入 RAM，並建立程序（Process）。Process 是一次正在執行的程式活動，以及這次執行所需的狀態和資源。

CPU 接著執行這個 Process 使用的程式指令。程式內容回答「要執行什麼」；Process 則代表「這份程式目前的一次實際執行」。所以 Program 和 Process 不相同。

兩者的差別

Program 可以留在儲存裝置上而不執行。Process 代表程式正在執行的一次活動；關閉程式後，這次活動結束，但程式檔案仍可存在。

03 / 一份程式，多次執行

每次開啟都可能是另一個 Process

同一份 Program 可以同時被開啟多次。每次開啟都可能建立獨立的 Process，各自處理不同文件或工作。它們使用相同的程式內容，但正在進行的活動和資料不必相同。

例如同一個計算程式可以開兩個視窗：一個計算 2 + 3，另一個計算 8 × 2。程式檔案相同，但每次執行各自有要處理的資料和結果。

06 / 與資安的關係

Process 的資料和資源需要受到限制

電腦可能同時執行多個 Process。作業系統會限制一個 Process 能存取的資料和資源，避免程式任意讀取其他 Process 正在使用的內容。這種隔離有助於降低錯誤或遭濫用時對其他工作造成的影響。

Process 能做什麼也和啟動它的使用者及權限有關。下一課會介紹檔案如何以路徑定位；0-7 再說明使用者與權限如何影響檔案操作。本課不深入作業系統的內部管理機制。

你已經知道

Program 是可執行的程式內容；Process 是這份程式的一次執行活動。作業系統載入程式並建立 Process，CPU 再執行其中的指令；同一個 Program 可以同時有多個 Process。
