使用者與權限

Users & Permissions

了解作業系統如何區分使用者，並依照檔案權限決定執行中的程式可以讀取、修改或執行哪些內容。

學完這一課，你可以

  • 說明作業系統為什麼要區分使用者。
  • 分辨 Read、Write、Execute 三種基本權限。
  • 描述 User、Process 和 File 如何一起影響一次操作能否進行。

01 / 使用者

為什麼作業系統需要 User？

使用者（User）是作業系統用來識別正在使用電腦的人或服務的帳號。使用者帳號讓系統能分辨不同工作和資料的歸屬，並依照需要決定允許哪些操作。

如果多個人共用一台電腦，系統不能假設每個人都應該查看或修改所有資料。區分使用者有助於保護彼此的檔案，也讓程式能在適當的使用者身分下執行。

02 / 權限

權限決定可以做什麼

權限（Permission）是作業系統用來規定使用者或程式能對資源進行哪些操作的設定。檔案的權限可能包括讀取、修改內容或把檔案當成程式執行。

  • 讀取（Read）：查看檔案內容。
  • 寫入（Write）：建立或修改檔案內容。
  • 執行（Execute）：要求系統把檔案當成程式啟動。

不是每個使用者都需要所有權限。例如，報告檔案可以允許某人讀取，但不允許修改；程式檔案也可以限制誰能啟動。

03 / User、Process、File

一次檔案操作會經過哪些角色？

使用者啟動程式後，作業系統會建立 Process。當 Process 嘗試讀取或修改檔案時，作業系統會檢查這次操作是否符合檔案權限。這裡的 User、Process、File 分別代表操作身分、正在工作的程式活動，以及被存取的資源。

06 / 與資安的關係

權限限制程式可以接觸的資料

程式可能出錯，也可能被不當使用。若每個 Process 都能讀寫所有檔案，一個程式的問題就可能影響其他使用者的資料。作業系統透過權限檢查限制可進行的操作，降低不必要的存取。

安全設定通常只授予工作所需的權限。這樣即使程式出現問題，它可造成的影響也較受限制。後續 Linux 和系統安全課程會再介紹如何設定與管理權限；本課不涉及權限命令或進階存取控制機制。

你已經知道

User 表示操作身分，Process 代表一次執行活動，File 是被存取的資源。Read、Write、Execute 描述不同操作；作業系統依照權限判斷操作能否進行。
