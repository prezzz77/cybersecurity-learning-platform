LEVEL 0 — FINAL REVIEW

Level 0 Review

Computer Fundamentals Review

用整體流程和實際情境檢查你是否能連結電腦、程式、作業系統、檔案與權限等基本概念。

完成這一頁後，你可以

  • 描述程式從儲存裝置載入、進入記憶體並由 CPU 執行的大致關係。
  • 說明作業系統、檔案系統、使用者和權限如何共同影響檔案存取。
  • 解釋 Terminal 命令如何要求作業系統操作資源。

01 / 學習順序

Level 0 的概念順序

以下順序表示本 Level 的教學安排，讓概念逐步建立。它不是電腦實際運作時唯一的先後關係；系統中的元件會依工作互相配合。

  1. Computer 電腦
  2. Data 資料
  3. Program 程式
  4. CPU 執行指令
  5. Memory / Storage 暫存與保存
  6. Process 一次執行活動
  7. File System 檔案與路徑
  8. User / Permission 身分與操作範圍
  9. Terminal 文字操作介面
  10. Operating System 資源管理

02 / 系統情境

把概念放進同一個情境

A. 使用者開啟一個程式

Program 檔案通常保存在 Storage。作業系統將執行所需內容載入 RAM，建立一次 Process 執行活動；CPU 執行其中的指令。作業系統會管理這次活動和所需資源。

B. 程式讀取 project/data.txt

假設目前位置是 project 資料夾的上一層，這是從目前位置出發的相對路徑。File System 根據資料夾結構定位檔案；Process 發出讀取要求時，作業系統還會依照目前 User 和檔案 Permission 判斷是否允許。

C. Alice 可以讀取檔案，Bob 不可以

作業系統辨認啟動 Process 的使用者身分，並檢查檔案權限。不同 User 的 Process 可能因此得到不同的存取結果；知道檔名並不代表一定有權讀取。

D. 使用者在 Terminal 輸入命令

Terminal 提供文字介面；Shell 解析命令並要求作業系統操作資源。作業系統依目前使用者與權限，處理相關 Process 或 File 操作，再將結果回傳給介面顯示。

E. 同一個程式開啟兩次

Program 檔案可以只有一份；每次開啟都可能建立新的 Process。每個 Process 是一次執行活動，可能使用不同的輸入資料。

F. 程式取得鍵盤輸入並顯示結果

作業系統協調輸入設備和螢幕等輸出設備。程式處理輸入資料，再把結果交給系統顯示；執行所需的指令和資料會由 CPU 與記憶體共同使用。

03 / 最終測驗

Level 0 檢查

共 8 題。每題選擇答案後按「確認答案」查看解析；尚未選擇時不會判定。

Level 0 Review 得分：0 / 8

1. 計算程式收到使用者輸入的 25，並計算 25 × 4。在這個情境中，25 比較接近什麼？

2. 程式正在執行，CPU 需要取得它正在使用的指令與資料。哪個位置最直接提供目前執行所需的內容？

3. 使用者開啟同一個程式兩次，哪個敘述最合理？

4. /home/alice/project/data.txt 在這個情境中最主要表示什麼？

5. User A 可以讀取 secret.txt，但不能修改它。哪種權限組合最符合？

6. 使用者在 Terminal 輸入 cd project，這個命令最直接涉及哪個概念？

7. CPU、RAM、Process、File、User 和 Permission 需要共同管理時，哪個概念負責提供這個管理架構？

8. Alice 在 Terminal 中執行一個儲存在 Storage 的程式。程式載入 RAM 後形成 Process，並嘗試讀取 data.txt；Alice 沒有讀取權限。哪個部分最直接造成「無法讀取」？

04 / 與資安的關係

安全建立在資源管理之上

程式處理資料、使用記憶體並讀寫檔案。作業系統依照使用者和權限管理這些操作；程式正確處理路徑和輸入，也能減少意外存取資料的風險。這些基本關係是後續學習資訊安全時會反覆用到的背景。

Level 0 完成後應理解的內容

  • 資料與程式的基本差異。
  • CPU 如何執行指令。
  • RAM 與 Storage 的用途差異。
  • Program 與 Process 的差異。
  • File System 如何透過路徑定位資料。
  • User 與 Permission 如何影響操作。
  • Terminal 如何提供文字命令介面。
  • Operating System 為什麼存在，以及它管理哪些資源。
